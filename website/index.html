Our Mission

What is Ohana Garden?

Ohana Garden is a community coordination and communication platform designed for Hawaiian communities in Puna, Hawaii, including Pahoa, Volcano, Hilo, and Kalapana.

At its heart, Ohana Garden enables community members to participate in voice-first conversation rooms where multiple personas interact, including human proxies representing people in specific roles, and entity agents representing gardens, plants, and places in the community.

The platform tracks community impact through metrics like meals shared, families served, and resources distributed, creating a living record of collective care and cooperation.

The Technology

Powered by Vessels

Vessels is an autonomous AI agent framework that provides the intelligent foundation for Ohana Garden's community coordination capabilities.

What is Vessels?

Vessels is an autonomous AI agent framework built on Agent Zero, extended with a unified graph-based storage layer using FalkorDB and Graphiti. It's a voice-first system where autonomous AI agents manage entities and relationships, with all runtime data persisted in a temporal knowledge graph.

Unlike traditional file-based AI systems, Vessels stores memories, conversations, knowledge, and settings in a single connected structure, enabling sophisticated reasoning about relationships and context over time.

🧠

Graph-Based Memory

All knowledge stored in FalkorDB as interconnected nodes, enabling relationship-aware reasoning and temporal tracking.

🎙️

Voice-First Interface

Natural voice interactions powered by Hume.ai with real-time emotion detection for empathetic, context-aware responses.

🤖

Multi-Agent Architecture

Agents work in hierarchies, delegating tasks to subordinates and coordinating through sophisticated communication protocols.

⚖️

Ethical Framework

Constitutional AI ethics engine validates all actions against 18 principles across safety, transparency, privacy, and fairness.

Features

How Vessels Powers Ohana Garden

01

Conversation Rooms

Multiple personas interact in voice-first rooms: human proxies (gardeners, coordinators), entity agents (plants, gardens, places), and direct human participants.

  • Human Proxy Agents represent community roles
  • Entity Agents give voice to gardens and nature
  • Real-time emotion detection
02

Dynamic Canvas System

Visual content appears contextually based on conversation, showing maps, calendars, impact metrics, and galleries.

  • Geographic maps of garden locations
  • Calendar scheduling for activities
  • Impact visualizations (meals, families)
03

Entity Ontology

A comprehensive system for representing community elements: plants, creatures, machines, places, biomes, resources, processes, and collectives.

  • Plants, trees, and garden entities
  • Locations and community spaces
  • Resources and workflows
04

Ohana Coordinator

A warm, supportive AI persona embodying Hawaiian values, helping coordinate community activities with patience and cultural awareness.

  • Embodies aloha, kuleana, laulima, mālama
  • Inclusive and encouraging
  • Culturally aware coordination

🔗 Graph Database

FalkorDB stores all data as connected nodes with Cypher queries, enabling relationship-aware searches and temporal tracking of when entities were created and accessed.

🔍 Hybrid Search

Graphiti combines semantic, keyword, and graph traversal search methods to find relevant information across the entire knowledge graph.

Agents use specialized tools for code execution, memory management, knowledge search, canvas generation, and agent-to-agent communication.
